# 원본 대비 개선 내역 — 양선재 님 AI-M1-1

이 파일은 **업로드된 과제 제출 ZIP을 기준으로** 작업한 정리 내역입니다. GitHub 원본 저장소의 최신 상태에 자동 반영된 것은 아닙니다.

## README 개선

- 외부 GitHub 첨부 URL에만 의존하던 이미지를 **로컬 `images/` 상대 경로**로 통일해, ZIP을 풀고 GitHub에 올려도 재현 가능하도록 변경했습니다.
- 여러 장을 한곳에 몰아서 나열하지 않고, **분석 질문 순서**로 그래프 1~7을 배치했습니다.
- 그림마다 **제목 · 무엇을 보여 주는가 · 왜 이 분석법을 사용했는가 · 해석 주의사항**을 추가했습니다.
- 대시보드 사진 2장은 분석 결과 그림과 분리해 `docs/images/`에 보관하고, 보너스 대시보드 설명 바로 아래에 표시했습니다.
- 기상 자료에서 혼동하기 쉬운 **격자 재분석, 공식 열대야 기준과의 차이, 이상치, 보간, 이동평균, 추세, 계절성, 잔차, MAE** 등을 초보자 기준으로 설명했습니다.
- CSV·Python·Streamlit 실행 순서와 작업 시 **기존 `REPORT.md` 덮어쓰기 주의사항**을 명시했습니다.

## 파일 정리

- 중첩 ZIP `seoul-temperature-analysis.zip` 1개 및 동일 그래프만 넣은 ZIP 1개: **개선본에서 제거**. 실제 프로젝트 파일은 바로 열리는 구조로 구성했습니다.
- 이미지 7개: 프로젝트 루트의 `images/`에 한 벌만 남겼습니다.
- 대시보드 캡처 2개: 원본 ZIP에서 상·하위 위치에 중복되어 있던 동일 파일 중 한 벌만 보존하고 `docs/images/`로 이동했습니다.
- `.git/`과 Python 캐시 `__pycache__/`, 이미지가 이미 있는 폴더의 `.gitkeep`: 제출용 ZIP에서 제외했습니다.
- 대시보드 설명용 문서 `DASHBOARD.md`는 `docs/DASHBOARD.md`로 배치하고 실제 사진 경로에 맞추었습니다.

## 보너스 시계열 분해

- 원본 코드의 `decompose()`와 `plot_decomposition()`이 이미 **구현된 상태**였습니다.
- **함수를 다시 만들거나 결과를 임의 수정하지 않았습니다.** 실행·수치 검증과 해설 문서 `docs/DECOMPOSITION_GUIDE.md`를 추가했습니다.
- `tests/test_decomposition.py`로 행 수와 분해 항등식, 성분 출력을 검증합니다.

## 보존 사항

- 원본 `analysis.py`, `fetch_data.py`, `dashboard.py`, 원본 `REPORT.md`, `requirements.txt`, 원본 CSV, `results/` 및 **원래의 그래프 7장**을 유지합니다.
- 원본 `REPORT.md`의 AI 사용 로그에 남은 `[ ]` 확인란은 작성자가 실제 확인해야 하므로 임의로 완료 표시하지 않습니다.
- 새로 촬영하지 않은 필터 변경 스크린샷을 실제 증빙인 것처럼 추가하지 않습니다.
